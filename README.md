# Schema Review Tool

A free, client-side schema.org structured-data scanner. Crawl a website (or paste a page's HTML) to see what JSON-LD, microdata, and RDFa it has, get suggested fixes, and copy a ready-made AI prompt to generate corrected markup.

Runs entirely in the browser — no backend, no AI credits, no data stored.

## Usage

Open `index.html` in a browser, or deploy it as a static site (e.g. Vercel).
